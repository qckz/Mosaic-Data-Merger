# Changelog

All notable changes to Mosaic Data Merger are documented here.

## 0.5.0

- Added CSV, JSON, JSONL, and STIX input support with CSV, JSON, JSONL, and STIX output.
- Added schema mapping, constants, transformations, filters, validation, rejection files, exclusions, wildcard inputs, provenance, and disk-backed deduplication.
- Added a packaged command-line interface: `mosaic-data-merger`.
- Restructured the code into a maintainable Python package and split the documentation into a quick-start README and configuration reference.
